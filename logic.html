Truth Tables

Build truth tables for logical connectives (discrete math) or for standard logic gates.

  1. 1
    WriteType an expression or pick a logic gate.
  2. 2
    BuildPress Build truth table.
  3. 3

1Type your expression

Try an example Tap one to load it and build its table

Order of operations Highest priority first

  1. ¬not1st · highest
  2. ∧and2nd
  3. ∨or3rd
  4. →if … then4th
  5. ↔if and only if5th · lowest

Brackets ( ) always go first. Operators at the same level group left to right, except → which groups right to left. Example: p ∨ q ∧ r means p ∨ (q ∧ r).

You can also type: ~ or ! for ¬, & for ∧, | for ∨, -> for →, and <-> for ↔.
